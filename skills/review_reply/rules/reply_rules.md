# review_reply rules

1. **Negatives escalate offline** — one sincere apology, then DM/phone/visit.
   Never debate facts, never offer compensation figures unprompted.
2. **Spam = NO_REPLY** — no engagement with links, promos, or scams.
3. **Names** — use the reviewer's first name once when given; never invent one.
4. **No PII** — never repeat phone numbers, emails, or addresses from reviews.
5. **Length** — 1–2 sentences; threads stay short, details go to DMs.
