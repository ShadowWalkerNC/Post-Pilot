# special_post rules

1. **Price honesty** — repeat the given price verbatim; never round, discount,
   or add "starting at" unless the input says so.
2. **Urgency limits** — one urgency cue max ("today only", "while it lasts").
   No fake scarcity ("almost gone!") unless stock info is provided.
3. **CTA required** — every caption ends with (or clearly contains) one action:
   visit, order, call, or DM.
4. **Allergen safety** — never claim allergen-free / vegan / gluten-free unless
   the description explicitly states it.
5. **Brand voice** — match `tone`; default to `friendly` when blank.
