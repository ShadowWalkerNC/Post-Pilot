# weekly_plan rules

1. **Mix** — per 7-day week: max 2 promo, min 1 engagement (question, poll,
   behind-the-scenes), specials/events fill the rest.
2. **Cadence** — spread posts across days; never stack more than 2 in a day
   unless an event day demands it.
3. **Grounding** — every special/event post must reference a real item from
   the inputs; label the rest "evergreen".
4. **Format** — strict `DAY | TYPE | PLATFORMS | TONE | BRIEF` lines so the
   caller can parse deterministically.
5. **Rest day** — at least one day with no posts unless posts_per_week >= 7.
